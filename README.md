# Лендинг ТРЛ — маркировка «Честный знак» на таможенном складе в Казани

Одностраничный сайт для ООО «Технические решения логистики» (ООО «ТРЛ»): услуги маркировки товаров «Честный знак» на собственном таможенном складе, включая алкогольную продукцию (лицензия РАР).

Требования — `TZ_landing_markirovka.md` (ТЗ v1.3); коммерческое предложение — `KP_landing_markirovka.md`.

## Стек и структура

Чистый HTML/CSS/JS, без сборки, без зависимостей.

```
index.html                                   — весь лендинг (разметка + стили + скрипты inline)
politika-obrabotki-personalnyh-dannyh.html   — политика обработки ПДн (типовой шаблон)
assets/                                      — фото склада заказчика (WebP)
```

На GitHub Pages (ветка `gh-pages`) публикуются только файлы лендинга — внутренние документы (ТЗ, КП) по адресу сайта не доступны.

## Локальный запуск

Зависимостей нет. Варианты:

- открыть `index.html` двойным кликом;
- через сервер (нужно для теста на телефоне / Lighthouse):

```bash
py -m http.server 8000
# http://127.0.0.1:8000/
```

## Подключение Яндекс.Метрики

1. Создать счётчик на metrika.yandex.ru.
2. В `index.html` найти `var METRIKA_ID = 'XXXXXXXX'` и вписать номер счётчика (замена в одном месте — код счётчика включится автоматически).
3. Цель «отправка формы» (`lead_form`) сработает при каждой заявке — увидеть её можно в Метрике → Отчёты → Конверсии. Настраивать цель в интерфейсе Метрики не нужно.

## Как посчитать заявки за период (критерий приёмки №7)

- **Текущий демо-режим:** каждая заявка открывает почтовый клиент с готовым письмом на irina_g26@list.ru — счётчик заявок = число писем «Заявка с сайта — обратный звонок» в почте (поиск по теме письма за период).
- **На постоянном хостинге:** те же письма приходят автоматически + дублируются ботом в MAX-организацию. Число заявок = письма по теме за период либо переписка MAX-бота.

## Подключение реальной доставки заявок (email + MAX)

Сейчас отправка выполняет функция `submitLead(lead)` в `index.html` (демо: mailto). На хостинге с серверным окружением заменить только её: POST-запрос к обработчику, который шлёт письмо (имя, телефон, дата/время) на email заказчика и вызывает MAX-бот организации. Антиспам (honeypot + проверка времени заполнения) уже в коде.

## Публикация (GitHub Pages)

Сайт доступен из ветки `gh-pages`. Обновление: внести изменения в `main`, затем скопировать файлы лендинга (`index.html`, `politika-obrabotki-personalnyh-dannyh.html`, `assets/` без негодных фото) в ветку `gh-pages` и запушить. Настройка Pages: Settings → Pages → Source: `gh-pages`.

## Проверка перед показом

1. `py -m http.server 8000` → консоль браузера без ошибок.
2. Форма: пустые поля → понятные ошибки; тестовые данные (заглушки) → письмо + подтверждение.
3. Критерии приёмки №1–7 из `TZ_landing_markirovka.md`.
